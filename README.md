# Comparable Analysis Example

This project is an educational example designed to perform comparable analysis for financial investors. It leverages Claude Skills, LLM Prompts, and simple scripts to generate financial analysis documents.

## Project Overview

The goal is to demonstrate how to automate financial tasks such as:
- Generating financial statements.
- Performing comparable analysis with peer group companies.
- Creating valuation analysis reports.
- Generating other user-requested financial documents.

## Tech Stack

- **IDE**: Antigravity
- **Language**: Python
- **Frontend**: None (Outputs are Markdown, CSV, or Text)
- **AI Tools**: Claude and Gemini CLI apps

## Directory Structure

- `/instructions` - Educational materials, instructions, and how-to guides for students
- `/scripts` - Educational scripts for students to learn from
- `/src` - Internal source code for project tooling (not student-facing)
- `/dataroom` - Source documents (e.g., SEC filings as PDFs)
- `/output` - Generated analysis outputs
- `/prompts` - LLM prompts for financial analysis tasks
